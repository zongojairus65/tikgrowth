# TikGrowth

Application d'analyse des performances pour créateurs TikTok.

- Site : fichiers HTML à la racine, terms/ et privacy/
- Serveur : functions/ (connexion TikTok via Login Kit)
- Secrets : à définir uniquement dans les variables d'environnement de Cloudflare (TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET). Ne jamais les mettre dans le code.
